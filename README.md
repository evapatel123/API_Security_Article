# How to Fix a Leaked API Key — Article Advertisement

A single-page promotional website for my freeCodeCamp article:

**[How to Fix a Leaked API Key: A Developer’s Guide to Git Security](https://www.freecodecamp.org/news/how-to-fix-a-leaked-api-key/)**

The website is designed as an interactive cybersecurity-themed advertisement that directs developers to the full article and highlights the importance of protecting API keys in Git repositories.

## About

This project serves as a standalone promotional landing page for the article. It uses a developer/cybersecurity visual style to communicate the risks of exposed API keys and encourage readers to learn how to properly respond to a leaked credential.

The page is intentionally contained in a single HTML file so it can be easily hosted as a static website.

## Features

* Single standalone HTML file
* Cybersecurity-themed visual design
* Animated interface elements
* Interactive navigation
* Responsive layout
* Article-focused promotional content
* Direct link to the full freeCodeCamp article
* No backend or server-side dependencies

## Article

Read the full article on freeCodeCamp:

**https://www.freecodecamp.org/news/how-to-fix-a-leaked-api-key/**

### What the article covers

The article provides a practical guide to responding to an accidentally exposed API key and discusses Git security practices developers can use to reduce the risk of credentials being committed or exposed.

## Running Locally

No build process is required.

Simply open the HTML file in a modern web browser.

For example:

```text
index.html
```

You can also serve it through a local development server if you prefer.

## Deployment

Because this is a static HTML page, it can be hosted using services that support static websites, including GitHub Pages.

If deploying with GitHub Pages, make sure the main HTML file is named:

```text
index.html
```
